## 📋 Workflow Templates

### ZORT Daily Sales Template

**File**: `workflows/zort_daily_sales_template.json`

**Purpose**: Sync daily sales data from ZORT API

**Trigger**: Scheduled (daily at 23:30)

**Flow**:
```
1. Cron Trigger (23:30 daily)
   ↓
2. HTTP Request → ZORT API (GET /sales)
   ↓
3. Transform Data (JSON)
   ↓
4. HTTP Request → Private API (POST /profiles)
   ↓
5. Log Results
```

**Nodes**:
```json
{
  "nodes": [
    {
      "name": "Cron Trigger",
      "type": "n8n-nodes-base.cron",
      "parameters": {
        "triggerTimes": {
          "item": [{"mode": "custom", "cronExpression": "30 23 * * *"}]
        }
      }
    },
    {
      "name": "Fetch Sales",
      "type": "n8n-nodes-base.httpRequest",
      "parameters": {
        "url": "={{$env.ZORT_BASE_URL}}/sales",
        "method": "GET",
        "headers": {
          "X-Store-Name": "={{$env.ZORT_STORE_NAME}}",
          "X-API-Key": "={{$env.ZORT_API_KEY}}",
          "X-API-Secret": "={{$env.ZORT_API_SECRET}}"
        }
      }
    },
    {
      "name": "Transform Data",
      "type": "n8n-nodes-base.set",
      "parameters": {
        "values": {
          "string": [{"name": "sales", "value": "={{$json.data}}"}]
        }
      }
    },
    {
      "name": "Save to Private API",
      "type": "n8n-nodes-base.httpRequest",
      "parameters": {
        "url": "http://private-api:3000/profiles",
        "method": "POST",
        "body": {
          "name": "Daily Sales {{$now.format('yyyy-MM-dd')}}",
          "data": "={{$json}}"
        },
        "headers": {
          "Authorization": "Bearer ={{$env.PRIVATE_API_TOKEN}}"
        }
      }
    }
  ]
}
```

## 🔗 Webhooks

### Webhook URLs

| Type | URL | Description |
|------|-----|-------------|
| Local | `http://192.168.1.248:5678/webhook/...` | Internal access |
| Public | `https://n8n.kankrittapon.online/webhook/...` | External access |

### Creating Webhooks

1. Open n8n UI
2. Create new workflow
3. Add "Webhook" node
4. Configure path and method
5. Activate workflow
6. Copy webhook URL

### Webhook Example

```json
{
  "nodes": [
    {
      "name": "Webhook",
      "type": "n8n-nodes-base.webhook",
      "parameters": {
        "httpMethod": "POST",
        "path": "my-webhook",
        "responseMode": "onReceived"
      }
    }
  ]
}
```

**URL**: `http://192.168.1.248:5678/webhook/my-webhook`

## ⚙️ n8n Configuration

### Environment Variables

```bash
# Core
N8N_HOST=localhost
N8N_PORT=5678
N8N_PROTOCOL=http
GENERIC_TIMEZONE=Asia/Bangkok

# Authentication
N8N_BASIC_AUTH_ACTIVE=true
N8N_BASIC_AUTH_USER=admin
N8N_BASIC_AUTH_PASSWORD=***

# Database
DB_TYPE=postgresdb
DB_POSTGRESDB_HOST=postgres
DB_POSTGRESDB_PORT=5432
DB_POSTGRESDB_DATABASE=n8n
DB_POSTGRESDB_USER=n8n
DB_POSTGRESDB_PASSWORD=***

# Security
N8N_ENCRYPTION_KEY=***
N8N_SECURE_COOKIE=false
```

### Credentials

n8n stores credentials encrypted in database:

| Credential | Type | Description |
|------------|------|-------------|
| ZORT API | Header Auth | ZORT API authentication |
| Private API | HTTP Header | Private API token |
| Player API | HTTP Header | Player API token |
| PostgreSQL | PostgreSQL | Database connection |

## 📊 Workflow Management

### List Workflows

```bash
# Via n8n API
curl http://192.168.1.248:5678/api/v1/workflows \
  -H "Authorization: Basic $(echo -n 'admin:password' | base64)"
```

### Export Workflow

```bash
# Export single workflow
curl http://192.168.1.248:5678/api/v1/workflows/{id} \
  -H "Authorization: Basic $(echo -n 'admin:password' | base64)" \
  -o workflow.json
```

### Import Workflow

```bash
# Import workflow
curl -X POST http://192.168.1.248:5678/api/v1/workflows \
  -H "Authorization: Basic $(echo -n 'admin:password' | base64)" \
  -H "Content-Type: application/json" \
  -d @workflow.json
```

## 🐛 n8n Troubleshooting

### n8n Won't Start

```bash
# Check logs
docker compose logs n8n

# Check database connection
docker exec n8n_zort_postgres psql -U n8n -c "SELECT 1;"

# Restart n8n
docker compose restart n8n
```

### Workflow Not Triggering

1. Check workflow is activated
2. Verify trigger configuration
3. Check execution history for errors
4. Review n8n logs

### Webhook Not Working

1. Verify webhook URL is correct
2. Check workflow is active
3. Test with curl:
   ```bash
   curl -X POST http://192.168.1.248:5678/webhook/my-webhook
   ```
4. Check cloudflare tunnel is running

### High Memory Usage

```bash
# Check n8n memory usage
docker stats n8n_zort

# Restart n8n
docker compose restart n8n
```
