# Core UX Law: 7 Actionable Questions & Tech Stack Specs

> **Core Philosophy**: Actionable Progression over Encyclopedic Text
> **Preferred Stack**: Next.js (App Router), TypeScript, Tailwind CSS, Lucide React, Radix/shadcn UI Patterns

---

## 🎯 The 7 Actionable Questions Framework

Every major phase & view answers:
1. 📍 **Where am I?** (Current Phase & Exact Gear Bracket)
2. 🎯 **What should I do next?** (Highest Priority Action Item)
3. 💡 **Why?** (Cost-to-benefit ratio & Stat ROI)
4. 🔓 **What does it unlock?** (New Monster Zones, AP Caps, PvP Brackets)
5. 📦 **What item/resource do I need?** (Precise Materials & Silver estimate)
6. 🚫 **What should I NOT consume?** (Item Safety Radar & Cron waste warnings)
7. 🏁 **When is this phase complete?** (Clear, Checkable Exit Conditions)

---

## 🛠️ Preferred Tech Stack & Architecture

- **Framework**: Next.js (App Router) + React 18/19
- **Language**: TypeScript (Strict type definitions for Gear, Spots, Classes, Buffs, Treasures)
- **Styling & Tokens**: Tailwind CSS v3/v4 with Custom Semantic Color Tokens
- **Icons**: `lucide-react` (High-contrast pure SVG icons)
- **Component Primitives**: Radix UI / shadcn-inspired Accessible HUD Components (Tabs, Dialog, Drawer, Tooltip, Accordion, Checkbox)
- **Data Engine**: Client-side reactive state with LocalStorage persistence + URL Query State Synchronization
