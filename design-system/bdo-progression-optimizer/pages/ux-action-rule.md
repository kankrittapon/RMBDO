# Core UX Law: ACTION > INFORMATION (5 Universal Questions)

> **Core System Philosophy**: Every major view and page must provide immediate actionability by answering the 5 Universal Questions.

---

## 🎯 The 5 Universal Questions Architecture

Every screen, tab, and drawer in the BDO Progression Optimizer MUST explicitly answer:

┌────────────────────────────────────────────────────────────────────────────────────────┐
│ ⚔️ ACTION OVER INFORMATION CARD (Instant Tactical Clarity)                             │
├────────────────────────────────────────────────────────────────────────────────────────┤
│ 1. 📍 WHERE AM I?                                                                      │
│    • Current Phase: Hyper-Endgame Transition (692 GS | 309 AP / 383 DP)                │
├────────────────────────────────────────────────────────────────────────────────────────┤

## 📱 Mobile Polish & Touch Ergonomics

- **Minimum Touch Target**: 44px x 44px for all buttons and toggles (with >= 8px spacing).
- **Text Reflow & Zoom Resilience**: Supports up to 200% browser zoom without layout breaking, truncation, or horizontal viewport scroll.
- **Micro-Interaction Budget**: All transitions clamped between 150ms - 200ms with explicit `prefers-reduced-motion` fallbacks.
